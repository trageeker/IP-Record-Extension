站点 IP 记录

站点 IP / 国家 备注 最近使用
没有记录。打开一个网站，点工具栏里的插件图标就会记录。

导出

JSON 可以完整导入回来（含各源明细）；CSV 方便用表格软件查看。

导入

支持本插件导出的 JSON 或 CSV。合并模式下同一条记录（相同 ID）保留较新的版本。

清空

删除全部记录，无法撤销。建议先导出备份。

记录方式

代理内核（mihomo / Clash Meta）

切换节点后还是旧 IP，多半是代理内核里的旧连接还挂在旧节点上，浏览器关不掉。开启后每次检测前先通过内核的外部控制 API 断开这些连接。适用于 Clash Verge Rev、Mihomo Party、FlClash、OpenClash 等 mihomo 内核客户端（在客户端里打开「外部控制」，查看端口和密钥）。

IP 源

同时查询勾选的源，按多数票得出 IP 和国家。至少保留两个。

选了某个源但它这次失败时，按「自动」处理。弹窗里每次检测后也可以在「各 IP 源结果」里点「用这个」临时改用某个源。

    快捷键

    默认 Alt+Shift+I 打开弹窗，可在 chrome://extensions/shortcuts 修改。
